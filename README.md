# Nesting & Teklif

Plaka yerleşimi (nesting), malzeme hesabı ve fiyat teklifi hazırlayan web uygulaması.

- DXF'ten parça okuma (Rhino 7/8 dışa aktarımları dahil)
- Malzeme / kalınlık bazında plaka yerleşimi, su yönü kontrolü
- Piyasa malzeme kütüphanesi
- Fiyat teklifi (PDF), yerleşim raporu (PDF), CNC için DXF
- Firma logosu, malzemeye göre tema

Tek dosyalık uygulama: `index.html`. Sunucu gerektirmez; veriler kullanıcının tarayıcısında saklanır.
